# Awaaz 🎵
Pakistani-first music & poetry platform

## ✨ Why Awaaz?
Global platforms ignore Urdu culture.
Awaaz brings it back — through music, poetry, and identity.

## 🎯 Features
- Desi Mood System (Dard, Ishq, Sukoon)
- Urdu + Roman lyrics
- Ghazal & Nazm section
- Artist storytelling
