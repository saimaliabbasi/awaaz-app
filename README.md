# Awaaz 🎵

A Pakistani-first music & poetry platform built around emotions, culture, and identity.

## ✨ Why Awaaz?
Global platforms don’t understand Urdu music deeply.
Awaaz brings music, poetry, and culture together in one place.

## 🎧 Features
- Desi Mood System (Dard, Ishq, Sukoon, Junoon, Jashn)
- Urdu + Roman Urdu lyrics
- Ghazal & Nazm section
- Artist stories & cultural context
- Coke Studio integration
